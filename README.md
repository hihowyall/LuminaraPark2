Luminara Park

A first-person psychological horror game built in Unreal Engine 5.

## About
Explore an abandoned theme park and uncover a dark consciousness-extraction conspiracy spanning 40 years. Solve intricate puzzles, encounter mysterious mascot characters, and discover the horrifying truth.
